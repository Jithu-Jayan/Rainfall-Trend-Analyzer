    Data & method

    Dataset

    The analysis is based on a rainfall dataset from Kaggle, covering India's precipitation over more than a century.

    Python stack

    The data was cleaned and aggregated with Pandas, processed numerically with NumPy, and analysed with SciPy (linear regression, standard deviation, variability). Python libraries were used for the data visualisation.

    This website

    Plain HTML, CSS and JavaScript. Every chart is drawn natively on canvas, with no external libraries, so it works offline and on GitHub Pages.

    Note: the regional and monthly figures shown here are rounded, indicative values prepared for visualisation. For exact figures, export your results from the Python analysis and replace the data arrays at the top of the script in this file.
