# Rainfall Trend and Variability Analyzer

A data analysis project that explores over 120 years of rainfall data across subdivisions of India (1901–2015), using Python to identify climate trends and seasonal variability patterns.

## Objective
To analyze climate variability patterns by studying historical rainfall data, performing trend analysis, and visualizing seasonal changes across Indian subdivisions.

## Dataset
- Source: India Meteorological Department (IMD)
- Coverage: 1901 to 2015
- Contains monthly, seasonal, and annual rainfall data across multiple subdivisions of India

## What This Project Does
- Loads and cleans real historical rainfall data
- Calculates the long-term rainfall trend using linear regression
- Identifies seasonal patterns across all 12 months
- Generates visualizations including a monthly bar chart, annual trend line, and a regional heatmap

## Key Findings
- Rainfall shows a slight decreasing trend of 0.07mm per year over 120 years
- July records the highest average rainfall, driven by the southwest monsoon
- The monsoon season (June–September) contributes the majority of annual rainfall
- High variability is observed across years, with notable peaks in the 1960s

## Tools Used
- Python 3
- Pandas
- Matplotlib
- Seaborn
- SciPy
